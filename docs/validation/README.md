# Validation summaries

This directory may hold concise future summaries that explain whether a calibration or detector assumption passed defined checks. A summary may include small tables, key numerical diagnostics, links to reproducible outputs, acceptance criteria, failure modes, and conclusions.

Every entry should identify:

- input runs and data locations;
- code revision and owning repository;
- database revision or exact constants source;
- configuration and cuts;
- observable definitions, coordinate conventions, and units;
- method and acceptance criteria;
- conclusions, limitations, and unresolved issues.

Raw/generated plots and calibration outputs are not tracked automatically. Small curated artifacts require project-leader approval and enough provenance to reproduce or interpret them. Do not substitute a selected plot for a documented method and quantitative conclusion.
