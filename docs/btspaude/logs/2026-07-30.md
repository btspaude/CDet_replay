# CDet–ECal timing-cut study review: 2026-07-30

The `plotECalCDetTimeCutStudy()` routine was reviewed against its requested selection and plotting behavior. It operates on the nested fourth-pass good-hit vectors, preserving event boundaries; defines `dt = tECal - tCDetLE`; and applies the inclusive `dtMinCut <= dt && dt <= dtMaxCut` requirement as its only additional hit-quality cut. The selected logical pixel ID is used only when filling the requested single-pixel LE plot.

The routine provides the uncut delta-t versus logical-pixel plot, uncut delta-t distribution with cut lines, post-cut LE/TE/TOT plots, selected-pixel post-cut LE plot, per-pixel hit efficiency with binomial uncertainty, and optional uncut delta-t-versus-TOT diagnostic. Explicit routine arguments control histogram ranges and bin width.

ROOT compilation succeeded. Synthetic tests confirmed inclusive timing-window endpoints, baseline and passing counts, selected-pixel counts, optional-diagnostic entries, and per-pixel efficiencies. Existing compiler warnings were outside this routine.

The project leader further specified that plotting-routine function signatures and ROOT histogram/canvas constructor calls should remain on one line. This preference is now part of the working agreement.

The reusable `IsCrossTargetRun()` helper checks a supplied run number against `scripts/cdet/runs.txt`. The efficiency canvas uses it to display `Cross-target run <number>` when the active `gRunNumber` is listed. A listed run and an unlisted run were both tested to confirm that the helper and annotation behave conditionally. Other plotting routines can reuse the same helper without duplicating file-reading logic.
