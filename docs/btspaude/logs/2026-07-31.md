# Selected-pixel timing fit: 2026-07-31

`plotECalCDetTimeCutStudy()` now fits the uncut ECal-minus-CDet delta-t distribution for the selected CDet logical pixel ID between `dtMinCut` and `dtMaxCut`. The model is a Gaussian signal plus a linear background, implemented as ROOT `gaus(0)+pol1(3)`. Initial values use the largest selected-pixel histogram bin inside the fit interval, an interval-based sigma estimate, and the average endpoint content for the background intercept.

The fit is drawn on the selected-pixel delta-t canvas together with the timing-window markers. The routine skips the fit when the selected pixel has no histogram content inside the requested interval. ROOT compilation succeeded, and a synthetic Gaussian-plus-uniform-background sample recovered a mean of about 84.64 ns and sigma of about 2.82 ns for injected values of 85 ns and 3 ns.
