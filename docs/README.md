# CDet project documentation

This directory is the return point for work on GEp-V CDet calibration.

Start with [CURRENT_STATUS.md](CURRENT_STATUS.md) and the newest file in [logs/](logs/). Then consult:

- [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md): project, software, repository, and path context.
- [WORKING_AGREEMENT.md](WORKING_AGREEMENT.md): roles, approvals, Git policy, and working standards.
- [DETECTOR_MODEL.md](DETECTOR_MODEL.md): detector hierarchy, channel arithmetic, conventions, and database observations.
- [CALIBRATION_NOTES.md](CALIBRATION_NOTES.md): structured notebook for calibration inputs, methods, and evidence.
- [DECISIONS.md](DECISIONS.md): approved decisions and their consequences.
- [TODO.md](TODO.md): possible next investigations; entries are not authorization to implement them.
- [validation/](validation/): guidance for future validation summaries and curated artifacts.

For a new ChatGPT or Codex task, read the status and newest log first, then the working agreement and the documents relevant to the task. Inspect current Git state, applicable repository guidance, and the affected source/database files before proposing changes.

Source code and database files are authoritative when they disagree with this documentation. Record disagreements rather than silently resolving them.
