# Clarification log: 2026-07-28

## Confirmed detector and DAQ facts

The project leader confirmed that the active database total of 2704 mapped channels is correct. Logical IDs 0–2687 are the physical CDet maPMT pixels. One extra 16-channel DAQ slot is mapped as IDs 2688–2703; only ID 2696 is used, as the reference signal. The other 15 mapped IDs are not physical CDet channels. By database order, ID 2696 is crate 63, slot 20, channel 40.

The commented `nchan = 2720` value is not active and does not represent the correct mapped total. Its historical origin is not needed to interpret the current 2704-channel mapping, although it may be explained or removed during a future approved database cleanup.

## Confirmed timing convention

CDet timing quantities stored in replayed ROOT files use 10 ps units. The `PlotElastic*.C` analysis macros multiply these values by `0.01` to convert them to ns. The upstream offline location that establishes this representation has not yet been identified and may be in general SBS processing rather than CDet-specific classes.

The current convention is acceptable for ongoing work. Any eventual change is a coordinated calibration/interface change: it must account for replay output, analysis cuts, calibration constants, plot labels, and compatibility with existing ROOT files, and therefore requires project-leader approval before implementation.

No code or database change was authorized or made during this clarification.
